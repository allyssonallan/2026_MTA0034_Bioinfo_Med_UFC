# Exercício swirl da MTA0034

O curso `MTA0034_Bioinformatica_em_R` contém a lição `Preparacao_para_Bioinformatica_em_R`. Ela revisa objetos, vetores, operações vetorizadas, filtros lógicos e data frames usando um pequeno exemplo de expressão gênica. A atividade depende apenas do R básico e do pacote `swirl`.

Para instalar a partir deste diretório durante o desenvolvimento:

```r
swirl::install_course_directory(
  "exercicios/swirl/MTA0034_Bioinformatica_em_R"
)
```

Para os estudantes, use o arquivo ZIP disponível na pasta `recursos` e as instruções publicadas no tutorial da disciplina.
